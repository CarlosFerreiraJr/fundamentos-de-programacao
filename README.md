# Fundamentos de Programação

Repositório criado para armazenar os exercícios desenvolvidos na disciplina **Fundamentos de Programação**, do curso de **Análise e Desenvolvimento de Sistemas - UNIG**.

## 📚 Sobre o projeto

Este repositório contém os programas desenvolvidos durante as atividades práticas da disciplina, com foco no aprendizado dos fundamentos da programação utilizando **C/C++**.

Os exercícios abordam conceitos como:

- Entrada e saída de dados
- Variáveis e tipos de dados
- Operadores aritméticos
- Expressões matemáticas
- Estruturas condicionais
- Lógica de programação
- Resolução de problemas utilizando C/C++

## 💻 Linguagem utilizada

Os programas foram desenvolvidos utilizando:

- C/C++
- Visual Studio Code
- Git e GitHub para controle de versão
